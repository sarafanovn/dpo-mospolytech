# Meridian

Портал информационной поддержки обучающихся филиалов Московского Политеха по программам дополнительного профессионального образования (ДПО).

## Структура

- `apps/web` — React + Vite фронтенд (личные кабинеты обучающегося и администратора)
- `apps/server` — Express + SQLite бэкенд (REST API, генерация документов)
- `packages/shared` — общие TypeScript-типы

## Запуск в разработке

```bash
npm install
npm run dev
```

Фронтенд: http://localhost:5173 (проксирует `/api` на бэкенд)
Бэкенд: http://localhost:4000

## Продакшн-сборка

```bash
npm run build
npm run start
```

Собранный фронтенд раздаётся тем же процессом на бэкенде (http://localhost:4000).

## Что реализовано

- Регистрация/вход (email + пароль), роли «обучающийся» и «администратор»
- Кабинет обучающегося: список курсов ДПО, подача заявки, анкета (13 полей по образцу прототипа), имитация электронного подписания, генерация и скачивание Заявления (PDF), Договора (PDF), Персональных данных (XLSX)
- Кабинет администратора: CRUD курсов, личные дела с поданными анкетами и документами, регистрация номера договора и подписание со стороны исполнителя, промежуточная/итоговая аттестация, формирование справок и сертификатов

Электронная подпись — имитация (визуальный штамп с ФИО и датой на PDF), без реальной криптографии.
