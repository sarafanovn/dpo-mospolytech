# Meridian

Портал информационной поддержки обучающихся Московского Политеха по программам ДПО.

## Быстрый старт (macOS, Linux, Windows)

Нужен [Node.js](https://nodejs.org) 22 или новее. Затем в папке проекта одна команда:

```bash
npm run setup
```

Она установит зависимости, создаст администратора по умолчанию (данные для входа печатаются в консоль) и запустит сайт и сервер.

- Сайт: http://localhost:5173
- API: http://localhost:4000
- Остановить: `Ctrl+C`

Повторный запуск (зависимости уже стоят): `npm run dev`

## Администратор

Администраторы не регистрируются через сайт, их создаёт команда в терминале.

**По умолчанию.** `npm run setup` сам создаёт администратора и выводит его данные в консоль:

- email: `admin@mail.com`
- пароль: `admin123`

Если такой администратор уже есть, шаг пропускается. Эти данные годятся только для разработки: перед продакшном создайте своего администратора (ниже) и смените пароль.

**Свой администратор.** Выполните в папке проекта (сервер при этом может быть запущен или нет):

```bash
npm run seed:admin -- <email> <пароль> "<Имя Фамилия>"
```

Например:

```bash
npm run seed:admin -- ivanov@mospolytech.ru MyPass123 "Иван Иванов"
```

Пароль не короче 6 символов. Имя в кавычках, если оно из нескольких слов. Если email уже занят, команда сообщит об ошибке. Без аргументов (`npm run seed:admin`) создаётся администратор по умолчанию.

Обучающиеся регистрируются сами на странице входа.

## Продакшн

```bash
npm run build
npm run start
```

Всё раздаётся с одного адреса: http://localhost:4000. Для продакшна задайте переменную `JWT_SECRET`.

## Если что-то не работает

- Ошибка про `better-sqlite3` / `NODE_MODULE_VERSION`: удалите папку `node_modules` и снова выполните `npm run setup`.
- На Windows, если нужна сборка нативного модуля: установите «Build Tools for Visual Studio» или используйте актуальную LTS-версию Node, для которой есть готовые бинарники.

## Структура

- `apps/web` — React + Vite
- `apps/server` — Express + SQLite (база создаётся в `apps/server/data`)
- `packages/shared` — общие типы
